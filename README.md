# WhatsApp Bot Using Python and Playwright

This project demonstrates WhatsApp Web automation using Python, Playwright, and Excel input.

## Main Features

- Opens WhatsApp Web
- Reads contact information from Excel
- Searches for a contact
- Sends an authorized test message
- Records the execution result

## Technologies Used

- Python
- Playwright
- Microsoft Excel
- Visual Studio Code
- Git and GitHub

## Run the Project

```powershell
python playwright_assign.py
